# 📊 E-Commerce Sales Analysis | Power BI Dashboard
## 📌 Project Overview
This project focuses on analyzing e-commerce sales data using Microsoft Power BI to understand sales performance, product category contributions, city-wise revenue, and order status.
The dashboard presents key performance indicators (KPIs) and interactive visualizations to support data-driven business decisions.

## 🎯 Project Objectives

- Analyze monthly sales performance and trends.
- Identify top-performing product categories and products.
- Compare sales across different cities.
- Monitor order status distribution.
- Build an interactive dashboard with filters and slicers.
- Extract meaningful business insights from sales data.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and visualization
- **Microsoft Excel** – Dataset inspection and data preparation
- **Power Query** – Data cleaning and transformation, where applicable
- **DAX** – KPI calculations, where applicable

## 📂 Dataset Description

The dataset contains e-commerce order information with the following fields:

| Column | Description |
|---|---|
| Order ID | Unique order identifier |
| Order Date | Date of the order |
| Customer Name | Customer name |
| City | Customer city |
| Product | Product purchased |
| Category | Product category |
| Quantity | Number of units ordered |
| Unit Price | Price per unit |
| Discount | Discount applied |
| Sales Amount | Recorded sales value |
| Order Status | Current order status |

## 🧹 Data Cleaning & Preparation

The data preparation workflow includes:

- Checking duplicate records.
- Identifying and handling missing values.
- Standardizing column data types.
- Cleaning inconsistent text values.
- Validating sales figures.
- Reviewing cancelled orders and order statuses.
- Preparing data for visualization and analysis.

The final cleaning decisions should be documented based on the actual transformations performed.

## 📈 Key Performance Indicators (KPIs)

The dashboard is designed to display:

- **Total Sales** – Total sales value for the selected period.
- **Total Orders** – Number of orders based on the chosen counting method.
- **Total Quantity Sold** – Total units ordered.
- **Average Order Value** – Average sales value per order.

## 📊 Dashboard Visualizations

| Visualization | Purpose |
|---|---|
| Monthly Sales Trend | Track sales performance over time |
| Sales by Category | Compare revenue across categories |
| Sales by City | Identify high-performing cities |
| Top 5 Products by Sales | Highlight leading products |
| Order Status Distribution | Understand order fulfilment status |

## 🎛️ Interactive Filters

The dashboard includes the following planned filters:

- Date
- Category
- City
- Order Status

These filters allow users to explore sales performance across different segments.

## 💡 Business Insights

The following insights will be documented after validating the dashboard measures and cleaned dataset:

- Highest-performing product category.
- City contributing the most sales.
- Monthly sales trends and top-performing products.
- Returned and processing orders requiring further review.
